What just happened

    Add an A2A agent

    Paste the agent’s base URL or the full URL of its Agent Card. The client looks for /.well-known/agent-card.json (A2A 1.0), then /.well-known/agent.json (0.3).

    Don’t have an agent to try?
    • Deploy the companion Phrasebook Agent from the repo’s proxy/ folder to Cloudflare (free, one command). It is a real cross-origin A2A 1.0 agent, and the same Worker doubles as a CORS proxy.
    • Run any A2A sample server on your machine, e.g. http://localhost:9999. Localhost is allowed.
    • See the safety checks fire: try https://example.com (no card) or a real agent that needs a login.

    Host model & network

    Get a key ↗

    Your key is used only in your browser to call the provider directly. It is never sent to any agent or anywhere else. There is no server. Tip: use a key with a low spending limit.

    CORS proxy (optional)

    Most agents on the internet don’t let web pages call them (no CORS headers). A proxy you deploy yourself (see proxy/ in the repo) relays the request. Only agents you tick “use proxy” for go through it.
